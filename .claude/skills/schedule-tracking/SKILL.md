# スケジュール管理規約（AIDD プロジェクト）

## ステータス記法

```markdown
- [ ]  未着手
- [-]  進行中 🏗️  ← 作業開始時に必ず更新
- [x]  完了 ✅    ← 成果物確認後のみマーク
```

## SCHEDULE.md 更新タイミング

1. **作業開始時**: `[ ]` → `[-] 🏗️` に変更
2. **完了時**: `[-]` → `[x] ✅` に変更（成果物確認後）
3. **ブロッカー発生時**: `## ⚠️ ブロッカー・課題` セクションに追記
4. **フェーズ完了時**: `## 📊 進捗状況` の全体進捗を更新

## 進捗状況セクションの更新

```markdown
## 📊 進捗状況
- **全体進捗**: XX%
- **現在フェーズ**: Phase N (フェーズ名)
- **アクティブタスク**: 作業中タスク名
```

## Next Action の更新

タスク完了後は `## 🚀 Next Action` を次のタスクに更新する：

```markdown
## 🚀 Next Action
\`\`\`bash
# 次に実行すべきコマンド
Read agents/[agent].md and [task description]
\`\`\`
```
