# /project:review

## 概要
コードレビューを実行し、品質・セキュリティ・パフォーマンス・保守性を総合的にチェックするコマンド。

## パラメータ
- `target` (省略可): レビュー対象 — `all`（デフォルト）| `frontend` | `backend` | ファイルパス

## 手順
1. 引数に応じてレビュー対象を決定する（省略時は `all`）
2. **フロントエンド** (`frontend/` 配下) をレビューする場合:
   - `tsconfig.json` で strict mode が有効か確認する
   - `.ts` / `.tsx` ファイルで `any` 型の過剰使用がないか確認する
   - `src/types/` ディレクトリが存在するか確認する
   - `.map()` に `key` prop が付いているか確認する
   - インラインスタイルの使用を確認する
3. **バックエンド** (`backend/` 配下) をレビューする場合:
   - `.go` ファイルでエラーハンドリング (`if err != nil`) が適切か確認する
   - `package main` が `cmd/` 配下にあるか確認する
   - 公開関数にコメントが付いているか確認する
   - `docker-compose.yml` のヘルスチェック・リソース制限・ネットワーク設定を確認する
4. **特定ファイル** を指定した場合はそのファイルのみをレビューする
5. 検出された課題をまとめ、各担当エージェントへの推奨アクションを Skills 記法で提示する
