# /project:plan

## 概要
SCHEDULE.md を確認して現在の進捗状況を分析し、次に取り組むべきタスクを提示するコマンド。

## 手順
1. SCHEDULE.md を読み込む
2. `[x]` 完了・`[-]` 進行中・`[ ]` 未着手 のタスクを集計し、現在のフェーズと進捗率を計算する
3. 進行中（`[-]`）のタスクをすべて列挙する
4. 未着手（`[ ]`）タスクのうち、次に着手すべきものを最大5件選ぶ
5. ブロッカー・依存関係・課題として記載された行を抽出する
6. 現在のフェーズに合わせた推奨アクションを生成し、Skills 記法で提示する

## 出力フォーマット

```markdown
## 📊 プロジェクト進捗状況

### 🎯 現在のフェーズ
**Phase X: フェーズ名** (進捗: XX% - X/Xタスク完了)

### 📋 次に取り組むべきタスク
🏗️ [進行中タスク名]
📋 [未着手タスク名]
...

### ⚠️ ブロッカー・課題
- [課題内容]

### 💡 推奨アクション
[フェーズに応じた推奨事項]

### 🚀 次のコマンド提案
```bash
# アーキテクト設計確認
/agent-architect 認証方式を最終決定してください

# バックエンド実装
/agent-backend ユーザー認証APIを実装してください

# DevOps環境準備
/agent-devops docker-compose.dev.yml を作成してください
```

---
*このレポートは `/project:plan` コマンドにより生成されました*
```
